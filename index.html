Projects 💡

Tic-Tac-Toe Online

June → August 2020

This is a full-stack web application built using the MERN stack (MongoDB, Express, React, Node.js) as well as Tailwind CSS. I implemented APIs for both user login and the game logic itself. I used Axios to allow requests to be made from the frontend to the backend. Overall the application allows users to login and register for new accounts, play multiple local tic-tac-toe games within a single login session, and view their win/ loss record.


ConnectMeWith

August 2020

My team members and I used the Twitter API to build a bot that when tweeted at by two users with the same topic, would connect them via Twitter DMs. The bot promotes continued discussion about important social issues like BLM and LGBTQ+ rights. Our project won the "Twitter For Everyone" hackathon category.


Spotify Playlist Generator

June 2020

This is a Twitter bot written in Python that when tweeted at with a username and artist name, communicates with Spotify's API to create a playlist of the given artist’s top 10 tracks in the user’s library. This was my first time playing around with third-party APIs and I learned a lot building it.


Get It Done!

January → April 2020

This is a desktop application adhering to OOD design written in vanilla Java with a GUI built using the Swing framework. The application allows users to sign in, add, view, update, and delete tasks to/ from their Task List. It was my term project for CPSC 210.
